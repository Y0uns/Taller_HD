# SansaWeigh

¡Bienvenido al repositorio del microservicio SansaWeigh!

## Documentación Oficial

Toda la documentación arquitectónica, reglas de negocio, manuales y Swagger se encuentra hosteada localmente utilizando **Docsify**.

Para visualizarla, simplemente usa Docsify-CLI (si lo tienes instalado):

```bash
docsify serve docs
```

Y visita `http://localhost:3000` en tu navegador.

*(Si no tienes Docsify CLI, puedes abrir el archivo `docs/index.html` en un servidor local, o instalar Docsify globalmente con `npm i docsify-cli -g`).*
