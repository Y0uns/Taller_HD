# SansaWeigh - Documentación Oficial

Bienvenido a la documentación oficial del microservicio **SansaWeigh**. Este proyecto fue desarrollado para gestionar el pesaje de cajas misteriosas utilizando una arquitectura basada en microservicios, caché, y bases de datos NoSQL.

## ¿Qué encontrarás aquí?

Utiliza la barra lateral para navegar por las siguientes secciones:

- **Arquitectura:** Detalles sobre cómo está construido el proyecto (patrones, componentes, etc.).
- **Reglas de Negocio:** Especificaciones funcionales sobre las restricciones de peso, horario y balanzas.
- **Manual de Usuario:** Guía rápida de uso de la API.
- **Swagger (API REST):** Documentación interactiva de los endpoints expuestos (OpenAPI).
